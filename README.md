# Flake Releases

Public update files for the personal macOS app [Flake](https://github.com/TimurKamnev/Flake).

- `appcast.xml` is the signed Sparkle update feed.
- `Flake-<version>.zip` contains the corresponding macOS application.
- `Flake-<version>.md` contains short release notes.

The source repository is private. Flake is based on [Snowhush](https://github.com/mbezruchko/Snowhush) and remains subject to the PolyForm Noncommercial 1.0.0 license included inside the application bundle.
